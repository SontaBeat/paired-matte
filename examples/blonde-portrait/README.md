# 写实金发人物

![原图、灰底、遮罩与黑白底合成](comparison.jpg)

尺寸：1145 × 1374。关注金色散发、针织衣料和主体不透明区域。“写实”仅描述画面风格，不代表已验证为相机实拍。

## 文件与复现

- [原图](source.png)、[#808080 灰底图](solid.png)、[L 模式灰度遮罩](alpha.png)、[透明 PNG](cutout.png)。
- [深色底预览](preview-black.png)（#111111）、[白底预览](preview-white.png)。
- [网页参数](settings.json)、[来源与 SHA-256](manifest.json)。

在根目录网页工具中导入 solid.png 和 alpha.png，选择“通用 · 保留原遮罩”，底色 #808080，黑场 0、白场 1、反推 0.90、灰边清理 0、白纱中和 0；不允许缩放遮罩。不要给金发套用会改变颜色的白纱预设。

## 流程与检查

2026-09-17 在 Safari 中使用 ChatGPT 网页版完成：原图生成灰底，重新上传该灰底生成遮罩，再用本地网页导出。保留中央人物、头发、衣服、项链和随身包，移除街道环境与其他人。

第一版遮罩把项链、部分针织袖子和浓密头发内部误判为半透明，未采用；重新上传同一灰底纠正后采用第二版。检查在尚未按遮罩裁边的灰底上进行，未见明显整体位移；黑白底合成检查中主体保持不透明，外围细发保留灰度。格式检查不能证明所有发丝逐像素无误。

导出的透明 PNG 与案例导出结果像素一致；Alpha 与输入遮罩最大相差 2/255，保留并披露该网页导出差异，没有为了消除差值重新改图。生成式处理可能重绘面部或发丝，不等于保留原图全部像素或恢复真实 Alpha。
