# 珍珠白半透明纱物

![原图、灰底、遮罩与黑白底合成](comparison.jpg)

尺寸：973 × 1616。关注大面积透光薄纱、细丝、褶皱叠层，以及去除透过纱可见的木台。

## 文件与复现

- [原图](source.png)、[#808080 灰底图](solid.png)、[L 模式灰度遮罩](alpha.png)、[透明 PNG](cutout.png)。
- [深色底预览](preview-black.png)（#111111）、[白底预览](preview-white.png)。
- [网页参数](settings.json)、[来源与 SHA-256](manifest.json)。

在根目录网页工具中导入 solid.png 和 alpha.png，选择“通用 · 保留原遮罩”，底色 #808080，黑场 0、白场 1、反推 0.90、灰边清理 0、白纱中和 0；不缩放遮罩。这次没有使用白纱经验预设，避免进一步改动已经生成的透明度和色彩。

## 本次流程与检查

2026-09-17 在 Safari 中使用 ChatGPT 网页版生成灰底图，要求只保留纱、去掉木台和透过纱可见的木纹，再重新上传该灰底生成配对遮罩，最后用本地网页导出透明图。

薄纱用连续灰度表达，丝线和高密度叠层更亮，没有把整片纱填成白块。遮罩转为 L 模式，清除 0–8 的近黑噪声，白场阈值保留 255；阈值可能损失最弱细丝，不能理解为真实透明度标定。灰底图在遮罩为零区域统一为精确 #808080。

在原始灰底上叠加轮廓检查，未见明显整体位移；黑白底合成可见细丝与透光变化，白底对比较低是白色薄纱的展示特性。去掉木台后不可直接观察的材质颜色由模型估计，不是无损恢复。

导出的透明 PNG 与本次已交付结果像素一致；Alpha 与输入遮罩最大相差 2/255，保留该网页导出差异。生成灰度没有真实 Alpha 对照，不保证任意背景上的物理准确性。
