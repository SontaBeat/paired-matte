# 演示素材与来源

五组图由作者提供用于项目演示：三组历史素材、两组 2026-09-17 新增网页版处理结果。本项目不将它们标注为人工实拍、真实 Alpha 标注或特定模型的标准测试集。

每组 `source.png` 为输入，`solid.png` / `alpha.png` 为配对成品。前三组 `cutout.png` 是本次用公开项目网页重新导出的结果；人物与纱物两组是从已验收的网页导出图复制的像素。`preview-black.png` / `preview-white.png` / `comparison.jpg` 是从结果确定性合成的展示图（深色 #111111、白色 #FFFFFF）。参数在 `settings.json`，尺寸、来源与文件哈希在 `manifest.json`。

历史记录：白纱女剑士与双人法器两组的配对图使用 Codex 内置图像生成工具生成；白发男剑士的纯色原始结果来自早期网页流程，遮罩曾错位，之后通过内置生图重新生成并完成局部检查。没有保留可供公开验证的完整网页生图日志，故不宣称已重跑网页版全过程。

新增记录：写实金发人物与珍珠白纱物均在 Safari 中使用 ChatGPT 网页版生成纯色图及配对遮罩，然后经本地工具导出。人物第一版遮罩有错误透明区域，纠正后采用第二版；纱物移除了木台，保留连续灰度。两组均检查原始灰底上的轮廓叠加与黑白底合成，不宣称逐像素无误。写实人物的画面风格不证明其为真人实拍，作者已确认其为本人制作并授权用于本项目演示。
