## 复现方式

```bash
npm ci
npm run build
npx playwright install chromium
npm test
npm run check
python3 -m pip install -r requirements.txt
python3 scripts/verify_examples.py
```

若使用本地 Chrome，可通过 `CHROME_PATH` 指定可执行文件。测试截图与临时下载放入被 Git 忽略的 `test-results/`。

更新示例导出应明确执行 `BUILD_EXAMPLES=1 npm test`，然后运行 `python3 scripts/render_examples.py` 重建预览和 SHA-256 记录。普通 `npm test` 不覆盖示例。
